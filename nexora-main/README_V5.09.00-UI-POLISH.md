# V5.09.00 — NEXORA UI Polish

Cette release conserve l’architecture LIA de V5.08.59→63 et applique une finition ciblée de l’interface publique et de la navigation.

## Changements

- **Hero accueil** : déplacement du bloc de conversation de Nexo afin qu’il ne masque plus le téléphone, avec positionnement responsive.
- **Navigation mobile** : ajout d’un contrôle **Mode clair / sombre** directement dans le menu latéral.
- **Accueil mobile** : le menu hamburger de la landing page ouvre désormais réellement la navigation publique.
- **Logo** : remplacement du wordmark PNG par un **SVG vectoriel** dans l’en-tête et le hero pour supprimer la pixellisation lors du redimensionnement.
- **Responsive** : dimensions et positions du logo, du téléphone et de la bulle Nexo ajustées pour les écrans mobiles/tablettes.
- **Version package** : `0.1.113`.

Aucune nouvelle autorité IA n’est introduite : la frontière de gouvernance LIA V5.08.59→63 est conservée.
