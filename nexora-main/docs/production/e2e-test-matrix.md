# V5.10.01 — E2E réel

Staging-only manual/browser matrix. This document does not claim execution without connected services.

- Registration, login, logout, session expiry, password recovery.
- Onboarding with and without bank connection.
- Open Banking: connect, callback, sync, 90-day lifecycle, re-authentication, revocation.
- Transactions, budgets, goals, dashboard and cross-domain consistency.
- LIA: context, recommendation, evidence, human approval gate, refusal of financial writes.
- Enterprise: verified SIRET, employee access, separation from personal workspace.
- Stripe: customer/payment/refund/webhook lifecycle.
- Admin: analytics, Open Banking supervision, LIA governance.
- Mobile/tablet/desktop and light/dark navigation.

Exit criteria: no P0/P1 defect; no unauthorized data access; no financial write without explicit approval.
