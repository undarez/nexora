# NEXORA v5.06.27 — Memory Consolidation Kernel

Ajoute une couche de consolidation entre Reflection/Learning et la mémoire durable.

## Principes
- Les signaux de réflexion deviennent des candidats de mémoire, pas des vérités.
- Faible confiance => `hold`.
- Les corrections utilisateur restent à valider.
- Les conflits sont conçus pour être quarantainés plutôt qu'écraser une mémoire existante.
- La provenance du signal et son score de qualité sont conservés.
- Aucune mutation durable, validation ou autorisation financière n'est accordée par ce kernel.
- La gouvernance mémoire existante reste l'autorité.

## Chaîne cognitive
Reasoning → Planning → Critique → Decision → Policy/Decision Gate → Action → Reflection → Learning → **Memory Consolidation** → Memory Governance

## Validation
`npm run lia:memory-consolidation-kernel`
