# NEXORA V5.08.32 — LIA Financial Reasoning

Adds a deterministic explanation layer comparing the current and previous month from available transactions.

## Guarantees
- Identifies observed changes in income, expenses and net flow.
- Ranks category-level drivers of expense variation.
- Reports confidence and limitations.
- Never treats category correlation as proof of causality.
- Never authorizes financial writes or counterfactual claims.
- Appends the reasoning only for questions where comparative/explanatory analysis is relevant.
