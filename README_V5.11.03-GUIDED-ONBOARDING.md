# V5.11.03 — Parcours guidé utilisateur NEXORA

Ajout d'un parcours guidé directement dans `/aide`.

## Objectif

Aider une personne qui connaît peu la finance à prendre NEXORA en main sans jargon ni surcharge d'information.

## Parcours

1. Regarder sa situation
2. Comprendre ses dépenses
3. Organiser son argent avec le budget
4. Poser une question à LIA
5. Vérifier les informations et décider

La progression est locale au navigateur via `localStorage`. Aucun nouvel enregistrement financier ou profilage utilisateur n'est créé.

## UX

- progression 0–100 % ;
- cases à cocher ;
- liens directs vers les modules ;
- possibilité de recommencer ;
- message de fin ;
- contenu court et accessible ;
- utilisable sur mobile.

Cette version ne modifie pas le moteur financier, Open Banking, les permissions LIA ou les données financières.
