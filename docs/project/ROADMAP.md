# NEXORA — Roadmap

## Cycle 1 — Cadrage
Establish objective, scope, architecture, governance, requirements, risks, planning, test/acceptance framework and project dashboard.

## Cycle 2 — Stabilisation
Finish the current architectural audit sequence, resolve CI/Vercel issues, verify tests and establish a clean baseline.

## Cycle 3 — Generic Agent Runtime
Complete separation between generic orchestration and financial-domain authority.

## Cycle 4 — Tools / Permissions / Skills
Formalise registries, permissions, safe invocation and reusable Skills.

## Cycle 5 — Loops / Evaluation / Recovery
Make bounded execution, evaluator feedback and retry/recovery first-class.

## Cycle 6 — Learning
Govern memory, knowledge, strategy and procedure improvement.

## Cycle 7 — Multi-agent and routing
Strengthen delegation, model routing and specialist-agent coordination.

## Cycle 8 — Production hardening
Security, observability, performance, incident readiness and release certification.

## Explicitly excluded
PC-local control and Stream Deck are not milestones of this roadmap.
