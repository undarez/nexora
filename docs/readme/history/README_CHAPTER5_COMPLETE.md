# NEXORA — Chapitre 5 — Mission autonome complète

Le chapitre 5 ferme la boucle d'exécution autonome durable :

`objectif → contexte durable → Knowledge/Skills → plan borné → outils autorisés → observation → vérification → opposition/challenger → évaluation → mémoire → reprise`.

## Étapes terminées

- runtime durable et récupération après timeout/crash ;
- chargement du contexte financier et de la mémoire durable ;
- sélection gouvernée des outils en lecture seule ;
- exécution bornée et anti-répétition ;
- vérification déterministe des observations ;
- opposition learning avant consolidation ;
- mémoire épisodique et apprentissage procédural ;
- évaluation des Skills après mission ;
- état d'objectif persistant et reprise via cron/continuations.

Aucune étape de ce chapitre n'accorde une autorisation financière supplémentaire.
