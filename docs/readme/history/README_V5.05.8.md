# NEXORA v5.05.8 — Homepage Hero & Branding

## Objectif
Renforcer immédiatement l'identité NEXORA sur la page d'accueil avec un logo en gros plan, sans remplacer le hero produit existant.

## Modifications
- Ajout d'un bloc de marque NEXORA au sommet du hero.
- Logo `/nexora-logo.svg` affiché en grand dans un conteneur premium.
- Wordmark NEXORA et signature « Votre intelligence financière ».
- Mise en page responsive desktop/mobile.
- Effet de profondeur/glow discret et animation flottante désactivée automatiquement avec `prefers-reduced-motion`.
- Le reste du hero, les CTA et le dashboard de démonstration sont conservés.

## Sécurité / logique
Aucune modification des données financières, de l'authentification, de LIA ou des règles d'autonomie.

## Validation
Modification statique vérifiée. Le build Next.js complet n'est pas déclaré validé dans l'environnement de génération lorsque les dépendances complètes ne sont pas disponibles.
