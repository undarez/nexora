# NEXORA V5.06.10 — Chapitre 1.1 Autonomous Financial Agent

Cette version étend la boucle autonome avec un autopilote financier déterministe et gouverné.

- observation des transactions et inférence d'enveloppe à haute confiance;
- synchronisation contrôlée des transactions vers `transaction_envelope_links`;
- prédiction des dépenses récurrentes sans créer de fausses transactions;
- détection de dérives budgétaires, risques de trésorerie et contrats à surveiller;
- persistance des prédictions et opportunités;
- notifications proactives dédupliquées;
- préférences d'autopilote avec désactivation immédiate;
- intégration au Cron LIA existant;
- les actions sensibles restent human-gated.

Version applicative: 0.1.40
