# NEXORA V5.08.20 — Legal & Product Foundation

Cette version ajoute le socle produit public et juridique à finaliser avant commercialisation.

## Ajouts
- `/a-propos`
- `/contact`
- `/faq`
- `/rgpd`
- `/cookies`
- `/mentions-legales`
- `/conditions-generales`
- `/cgv`
- `/charte`
- footer public avec navigation légale
- centre de préférences de confidentialité local, sans activation de traceurs optionnels
- configuration publique des informations légales via variables d'environnement
- régression `npm run legal:check`

## Point critique
Les informations entre crochets sont volontairement des placeholders. Elles doivent être remplacées par les données réelles de l'éditeur, de l'hébergeur, du point de contact RGPD et du médiateur lorsque requis, avant une mise en production commerciale.

Cette version ne constitue pas un avis juridique. Une validation par un professionnel du droit reste recommandée avant lancement public.
