# V5.11.02 — Guide utilisateur NEXORA

Ajout d'une page `/aide` centralisant le guide « Bien utiliser NEXORA », les notices particulier et entreprise, le guide LIA, la sécurité et un mini-lexique.

Le contenu privilégie des phrases courtes, des exemples concrets et l'explication immédiate des mots financiers, avec un niveau de lecture volontairement très accessible sans infantiliser l'utilisateur.

Le lien **Aide & Guide** est ajouté à la navigation desktop et mobile.

Cette version ne modifie ni le moteur financier, ni Open Banking, ni les permissions LIA.
