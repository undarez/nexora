# NEXORA v5.06.25 — Decision Kernel

Ajout du Decision Kernel déterministe après Reasoning, Planning et Critique.

## Chaîne cognitive

Reasoning → Planning → Critique → Decision → Policy/Decision Gate → Action éventuelle

Le Decision Kernel :
- produit une disposition cognitive bornée ;
- peut demander recherche, clarification, replanification ou validation humaine ;
- bloque lorsqu'une condition cognitive critique reste non résolue ;
- ne lance aucun outil ;
- n'autorise aucune écriture financière ;
- laisse Policy Engine et Decision Gate comme autorités finales.

Aucune migration Supabase n'est nécessaire.
