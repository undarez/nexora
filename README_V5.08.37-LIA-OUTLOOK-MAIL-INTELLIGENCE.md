## Gmail / Outlook

- facture ;
- échéance/paiement ;
- banque ;
- abonnement.

Aucune conclusion financière n'est déduite du seul signal mail. Les corps et pièces jointes restent exclus par défaut et aucune action automatique n'est exécutée.
