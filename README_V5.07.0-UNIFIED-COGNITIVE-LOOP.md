# NEXORA v5.07.0 — Unified Cognitive Loop

## Objectif
Relier les kernels cognitifs existants en une seule orchestration déterministe et bornée.

## Chaîne
Reasoning → Planning → Critique → Epistemic → Causal → Scenario → Active Inquiry → Knowledge Synthesis → World Model → Temporal World Model → Decision → Reflection → Memory Consolidation.

## Autorité
Le Unified Cognitive Loop coordonne et produit des contraintes cognitives. Il n'autorise ni écriture financière, ni exécution d'outil, ni mutation de mémoire durable. Policy Engine et Decision Gate restent souverains.

## Intégration
`src/lib/lia/unified-cognitive-loop.ts` expose `runUnifiedCognitiveLoop()` et `summarizeUnifiedCognitiveLoop()`.

Aucune migration Supabase n'est nécessaire.
